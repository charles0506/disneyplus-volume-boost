Disney+ 網頁版音量偏小，這支 userscript 把播放音量放大（100%~600%，預設 250%），
並接壓縮器防止爆音、拉近對白和爆炸聲的音量差。

操作（播放時右上角小膠囊）：

- 點一下：開／關增強
- 滾輪 或 Alt+↑ / Alt+↓：每次 ±25%
- Alt+0：開／關
